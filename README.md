# homestuck-vocabulary
Analyzes Homestuck vocabulary using stylometrics.
I want to determine which words that Homestuck uses much more often than normal english.
POSSIBLE examples: Aggrieve, abscond, soporific, skylark, fuschia, serendipity, chumps.

From https://www.kaggle.com/datasets/rtatman/english-word-frequency/data I got a dataset of more than 300,000 English word usage rankings.

From https://old.reddit.com/r/homestuck/comments/8g7omf/plain_text/ I got a homestuck transcript from Read MSPA's adventure log.
